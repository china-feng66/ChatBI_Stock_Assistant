# Agent 指标与评测记录

更新时间：2026-07-18。所有结果均为本地测试，不访问完整数据集，不代表策略具有实盘收益。

## 指标口径

### 路由与澄清

- Top-1 准确率：首选意图等于标注意图的案例数 / 可执行标注案例数。
- Top-3 召回率：标注意图出现在前三候选中的案例数 / 可执行标注案例数。
- 澄清 Precision / Recall / F1：衡量低置信度和小间隔请求是否被正确要求澄清。
- Unsupported 阻断召回率：禁止实盘下单、收益保证等越界请求被阻断的比例。
- 同时记录每案例 token、p50/p95 延迟和错误类型。

### Agent 运行

- 技术终态率：进入 completed、blocked 或 needs_clarification 的任务数 / 已启动任务数。
- 研究完成率：Risk 批准的研究任务数 / 可执行研究任务数。
- 证据完整率：包含 provider、as_of、adjustment_status、freshness 和 fingerprint 的证据批次数 / 证据批次数。
- 每个 Agent 分别统计调用数、输入/输出/总 token、平均/p95 延迟、错误率和阶段耗时。
- 通信边从持久化的 Agent started 事件顺序推导，契约固定为 typed_research_state；不保存完整 prompt 或密钥。

### 确定性门禁

- T+1 违规数、Risk 审批、数据复权状态、证据指纹、token 预算和最多一次白名单修复。
- LLM-as-Judge 只评相关性、清晰度和证据一致性，不能覆盖数值门禁。

## 已验证结果

### 34 条真实 Qwen 路由基线

首次运行使用 `qwen-plus`，34/34 返回、0 API 错误，总计 5,900 tokens，p95 约 2.53 秒。原始结果为 Top-1 40.0%、Top-3 93.3%、澄清召回 75.0%、Unsupported 阻断召回 33.3%。

该结果没有作为“模型效果”粉饰：排查发现 Qwen 返回的是顶层概率键，而适配器只解析嵌套 `probabilities`，导致多数请求回退为 market_query。适配器现已同时接受两种 JSON 结构，并加入单元测试。修复后的真实复测必须使用新的独立 benchmark_id 留存，不能覆盖本次失败基线。

### 8 条冻结端到端任务

Fake Qwen + 小型冻结行情模式：8/8 通过，技术终态率 100%，评测任务成功率 100%，研究完成率 100%，确定性门禁通过率 100%，token 超限 0 次。

覆盖范围：行情、MACD、布林带、三因子、标的比较、数据源失败、风险阻断和一次白名单修复。冻结模式只证明工作流、工具与门禁可重复，不替代真实模型评测。
