# 课程来源与个人贡献

## 学习起点

本项目的学习起点是课程《项目实战：ChatBI 开发实战》。课程 baseline 演示了 Qwen-Agent、SQLite 股票查询、MACD/布林带、预测模型和 WebUI。课程资料用于理解问题域与复现基础流程，不作为“个人原创算法”的申报依据。

## 独立重构部分

在课程复现后，QuantQuery-A 重新设计并实现了以下工程部分：

- 用 LangGraph 和类型化 `ResearchState` 重构为 Planner、Data、Quant、Risk、Reporter 五 Agent 确定性工作流。
- 建立 LLM、TF-IDF、关键词三路意图融合及澄清门槛。
- 增加 SQLite WAL 任务状态、检查点、事件、token、行情缓存、评测和候选权重持久化。
- 增加 Tushare/AKShare 有界数据网关、来源一致性、复权、新鲜度、指纹、熔断和 stale 缓存语义。
- 实现 T+1 开盘成交、交易成本、布林带、价格成交量三因子和时间外推评估。
- 实现“Risk 数值门禁最终裁决 + 仅一次白名单修复”，不允许 Agent 修改成本、策略假设或风险阈值。
- 实现 React 研究工作台、任务/行情 WebSocket、图表、导出和评测监控面板。
- 建立冻结 Fake Qwen 测试、路由集、端到端任务集和 CI。

## 简历表述边界

可以表述为“基于课程原型完成独立工程化重构”，并明确个人负责的架构、数据治理、回测约束、评测监控与前端实现。

不能表述为：

- 课程中所有指标、模型或业务想法均为个人原创；
- 已发现稳定、可交易的 Alpha；
- 系统具备实盘、逐笔或交易级低延迟能力；
- 仅凭 Mock 评测就证明在线模型和真实行情长期稳定。

建议简历描述：

> 在复现 ChatBI 课程原型后，独立重构为 React + FastAPI + LangGraph 的五 Agent 量化研究工作台；通过三路意图融合、数据指纹、T+1 回测、确定性 Risk 门禁、一次白名单修复和冻结评测集，使自然语言研究任务具备可恢复、可监控、可审计的执行闭环。
